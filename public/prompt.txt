من در حال توسعه یک اپلیکیشن مدیریت کارهای روزانه با Next.js هستم. لطفاً ادامه کار را بر اساس مشخصات فعلی پروژه انجام بده.

## تکنولوژی‌ها

* Next.js نسخه 16.2.12
* React نسخه 19.2.4
* TypeScript
* Tailwind CSS نسخه 4
* IndexedDB با Dexie برای ذخیره‌سازی آفلاین
* PWA با Service Worker برای اجرای آفلاین
* Node.js نسخه 24.18.1

## وضعیت فعلی پروژه

اپلیکیشن یک Task Manager فارسی با رابط راست‌چین (RTL) است.

ساختار کلی:

```
app/
├── page.tsx              صفحه اصلی کارها
├── history/
│   └── page.tsx          صفحه تاریخچه فعالیت‌ها
├── layout.tsx

lib/
└── db.ts                 تنظیمات IndexedDB
```

## قابلیت‌های پیاده‌سازی شده

### صفحه اصلی (`app/page.tsx`)

* نمایش لیست کارهای روزانه
* افزودن کار جدید
* حذف کار
* تغییر وضعیت انجام شده/نشده
* نمایش درصد پیشرفت روزانه
* طراحی Responsive برای موبایل و دسکتاپ
* کاملاً RTL

### اولویت کارها

هر Task دارای اولویت است:

```ts
priority:
"low" | "medium" | "high"
```

نمایش:

* کم → سبز
* متوسط → زرد
* زیاد → قرمز

در Select مربوط به انتخاب اولویت هیچ آیکن یا Emoji وجود ندارد.

### ویرایش کار

کاربر می‌تواند:

* عنوان کار را ویرایش کند
* اولویت را تغییر دهد
* تغییرات ذخیره شوند

### تاریخچه (`app/history/page.tsx`)

تاریخچه در صفحه اصلی نمایش داده نمی‌شود.

صفحه جداگانه دارد:

```
/history
```

امکانات:

* نمایش فعالیت‌ها

* فیلتر نوع فعالیت:

  * همه
  * ساخته شده
  * انجام شده
  * حذف شده
  * بروزرسانی شده

* فیلتر زمانی:

  * همه زمان‌ها
  * امروز
  * ۷ روز اخیر
  * ۳۰ روز اخیر

مدل تاریخچه:

```ts
{
 id?: number;
 taskId?: number;
 title: string;
 action:
 "created" |
 "completed" |
 "deleted" |
 "updated";

 date: string;        // نمایش فارسی
 createdAt: number;   // برای فیلتر دقیق
}
```

## PWA

PWA اضافه شده ولی:

* در حالت development خاموش است.
* فقط در production تست می‌شود.

تنظیم فعلی:

```ts
disable:
process.env.NODE_ENV === "development"
```

به دلیل جلوگیری از تداخل Workbox با Next.js Fast Refresh.

برای تست:

```bash
npm run build
npm start
```

## مشکلاتی که حل شده

### مشکل Refresh مداوم

علت:
فعال بودن Service Worker در حالت dev.

لاگ مشکل:

```
workbox Router is responding to:
_next/static/chunks/*
manifest.json
```

حل شد با خاموش کردن PWA در development.

### مشکل Next.js 16 و Turbopack

تنظیم شده:

```ts
turbopack: {}
```

تا خطای webpack config ایجاد نشود.
